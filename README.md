## 技术构成

- `index.html` —— 单文件大屏，12 批预生成数据直接内嵌，**无外部依赖、无后端、离线可看**
- `straitwatch_core.py` —— 纯 Python 标准库的风险识别引擎（ `--seed 20261026` 固定口径 / `--random` 随机批次）
- `vault_server.py` —— 本机网页工作台（登录 → 项目库 → 内嵌大屏 → 手动 / 自动运行引擎）
